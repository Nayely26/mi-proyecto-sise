SISE – SISTEMA DE SOLICITUDES ESTUDIANTILES
==================================================

DESCRIPCIÓN
-----------
SISE es un prototipo de sistema web orientado a facilitar la gestión de solicitudes administrativas de estudiantes y egresados. Permite registrar solicitudes, consultar el estado de los trámites y organizar su derivación a las áreas responsables.

El proyecto está relacionado con la carrera de Arquitectura de Plataformas y Servicios de Tecnología Informática y busca contribuir a una atención institucional más ordenada, accesible y transparente.

OBJETIVO GENERAL
----------------
Desarrollar una plataforma web que facilite el registro, la organización y el seguimiento de solicitudes estudiantiles y de egresados, mejorando la gestión de los trámites administrativos.

FUNCIONALIDADES PRINCIPALES
---------------------------
- Inicio de sesión y registro de usuarios.
- Acceso según los roles del sistema.
- Registro de solicitudes administrativas.
- Referencia de documentos en formatos admitidos por el prototipo.
- Organización y derivación de solicitudes a las áreas correspondientes.
- Seguimiento de trámites mediante código de seguimiento o DNI.
- Libro de reclamaciones.
- Generación o impresión de reportes en PDF.
- Opciones de accesibilidad, como aumento del tamaño del texto, alto contraste y navegación mediante teclado.

USUARIOS DEL SISTEMA
--------------------
- Estudiantes y egresados.
- Secretaría General.
- Secretaría Académica.
- Coordinadores.
- Director.

FLUJO GENERAL DE LAS SOLICITUDES
--------------------------------
Las solicitudes son recibidas y revisadas por Secretaría General, que puede derivarlas al área correspondiente según el tipo de trámite. Las áreas responsables revisan las solicitudes y actualizan su estado para facilitar el seguimiento.

TECNOLOGÍAS UTILIZADAS
----------------------
- HTML5: estructura de las páginas.
- CSS3: estilos y presentación visual.
- JavaScript: interactividad y funcionalidades del prototipo.
- Visual Studio Code: entorno de desarrollo.

CÓMO EJECUTAR EL PROTOTIPO
--------------------------
1. Descarga o clona este repositorio.
2. Descomprime el proyecto si lo descargaste como archivo ZIP.
3. Abre la carpeta del proyecto en Visual Studio Code.
4. Abre el archivo index.html en un navegador web.
5. Explora las opciones disponibles en el prototipo.

ACCESIBILIDAD
-------------
El proyecto incorpora opciones orientadas a mejorar la experiencia de personas con distintas necesidades, como ajustes de tamaño del texto, alto contraste y navegación por teclado. La accesibilidad debe seguir evaluándose con usuarios y tecnologías de asistencia para comprobar su funcionamiento.

ESTADO DEL PROYECTO
-------------------
Prototipo académico en desarrollo. Algunas funciones, como el envío real de correos electrónicos, la autenticación segura, el almacenamiento de documentos en un servidor y la conexión con una base de datos, requieren una implementación adicional si aún no están integradas.

SEGURIDAD Y PRIVACIDAD
----------------------
No publiques contraseñas reales, datos personales de estudiantes ni documentos privados en este repositorio. Para un despliegue real se necesita autenticación segura, permisos verificados en el servidor y almacenamiento protegido de archivos.
